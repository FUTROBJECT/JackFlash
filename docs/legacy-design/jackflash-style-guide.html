JackFlash Design System

A warm, friendly, expressive visual language for kids' math practice — built on the brand foundations of Fauna Robotics: soft to the touch, safety-first, and full of character.

Colors, neutrals, geometry and type below are lifted from Fauna's live stylesheet and re-mapped to JackFlash's needs. Where Fauna optimizes for bold marketing display, JackFlash optimizes for legibility and encouragement — the one deliberate change is that text on bright fills uses ink (#180102) rather than cream, so every control clears WCAG AA.

Foundations

Design principles

Four ideas borrowed from Fauna's product language, translated for a learning app a child uses every day.

🤲

Soft to the touch

Generous rounded corners, gentle shadows, warm cream surfaces. Nothing sharp, nothing cold — the interface should feel safe to poke at.

🌱

Growth, not grading

Progress over perfection. Teal celebrates what's right; mistakes are a gentle clay-red "not quite," never an alarming red buzzer.

⚡

The flash of delight

Coral is the spark — saved for the one action that matters on a screen. Energy used sparingly reads as confidence, not noise.

😊

Expressive & human

Big friendly display type, playful color, room to breathe. The app has a personality kids want to come back to.

Using the tokens

Recommended format: CSS custom properties (+ a JSON source)

JackFlash is React 19 / Vite, so plain CSS variables drop in with zero build wiring, theme at runtime, and work in any component whether you use CSS Modules, Tailwind, or styled-components. That mirrors how your AQL token tool already thinks about variables.

Two files ship alongside this guide:

  • tokens.css — the :root variables. Import once in your entry CSS; reference as var(--color-primary).
  • tokens.json — W3C-style source of truth. Feed it to Style Dictionary to also emit iOS / Android / Tailwind targets as JackFlash grows.

Keep tokens.json authoritative; generate tokens.css from it so the two never drift.
